# Игра "GEMS"

Игровое поле разбито на квадраты разных цветов. Можно поменять 2 соседних местами, кликнув сначала на одном, потом на другом. Если в результате таких манипуляций 3 или более квадрата одного цвета оказались соседними (не обязательно попарно), они уничтожаются, остальные квадраты сдвигаются вниз, производится еще одна проверка на образование последовательности одноцветных и тд. При уничтожении квадрата может выпасть рандомный бонус в окрестности радиуса 3 квадратов, совершающий следующее:

1) Перекрашивание квадрата, куда попал бонус, и его произвольных 2 НЕсоседей в окрестности в цвет исходного квадрата, откуда выпал бонус
2) «Бомба» - уничтожает 5 произвольных квадратов на поле, включая тот, куда попала.

## Инструкция по сборке проекта (Visual Studio 2022)

### Шаг 1. Настройка стандарта языка
1. Откройте проект в Visual Studio.
2. Нажмите правой кнопкой мыши по проекту "GEMS" -> "Свойства".
3. В выпадающем списке сверху выберите "Все конфигурации" и платформу "x64".
4. Перейдите в раздел "Свойства конфигурации" -> "Общие".
5. В строке "Стандарт языка C++" выберите "Стандарт ISO C++17".

### Шаг 2. Подключение заголовочных файлов и библиотек SFML
1. В окне свойств перейдите в раздел "C/C++" -> "Общие".
2. В поле "Дополнительные каталоги включаемых файлов" укажите путь к папке "include" вашей библиотеки SFML.
3. Перейдите в раздел "Компоновщик" -> "Общие".
4. В поле "Дополнительные каталоги библиотек" укажите путь к папке "lib" вашей библиотеки SFML.

### Шаг 3. Указание зависимостей
1. В разделе "Компоновщик" -> "Ввод" найдите строку "Дополнительные зависимости".
2. Нажмите "Изменить" и добавьте в список следующие библиотеки:
   
sfml-graphics.lib
   
sfml-window.lib
   
sfml-system.lib
   
3. Нажмите "Применить", а затем "ОК".

### Шаг 4. Добавление динамических библиотек (.dll)
1. Перейдите в папку, где распакован SFML, и откройте каталог "bin".
2. Скопируйте оттуда три файла: "sfml-graphics-3.dll", "sfml-window-3.dll" и "sfml-system-3.dll".
3. Вставьте их прямо в корневую папку вашего проекта на компьютере (туда, где лежат файлы ".cpp" и ".h").
